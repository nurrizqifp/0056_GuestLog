# GuestLog

Aplikasi Android untuk mengelola daftar tamu undangan, konfirmasi kehadiran, dan buku ucapan pada acara pernikahan.

## Deskripsi

GuestLog membantu pasangan mempelai dan panitia penerima tamu mengelola undangan pernikahan secara digital. Mempelai dapat mengatur detail acara dan daftar tamu, tamu dapat mengonfirmasi kehadiran serta menulis ucapan doa, dan panitia dapat mencatat pengambilan suvenir di hari H. Rekap kehadiran dan bukti undangan dapat diunduh sebagai file di perangkat.
